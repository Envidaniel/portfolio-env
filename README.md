
# portfolio-env
A professional showcase of my software engineering devOps & cloud, projects, technical skills, and experience.

## 🚀 Features
- **Responsive Design**: Optimized for all devices and screen sizes.
- **Project Gallery**: Interactive display of key projects with source code and live demo links.
- **Contact Integration**: Easy-to-use contact form or social links.
- **Performance Optimized**: Built with modern best practices for speed and SEO.

## 🛠️ Tech Stack
- **Frontend**: React / Next.js
- **Styling**: Tailwind CSS
- **Deployment**: Vercel

## 🏁 Getting Started

### Installation
```bash
git clone https://github.com/Envidaniel/portfolio.git
cd portfolio
npm install
```

### Development
```bash
npm run dev
```
